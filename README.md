Более развёрнутое описание (для README / кейса)Я создал Telegram-бота CareerShift 
— советчика по выбору карьеры и профессии для двух аудиторий: подростков, которые
не знают, куда двигаться, и взрослых, которые выгорели на работе и ищут новый интересный
путь.Идея простая: вместо длинных тестов и списков «топ-10 профессий» бот ведёт диалог,
выявляет реальные интересы и предлагает мини-эксперименты. Человек пробует направление
на практике (короткое задание, мини-проект, разговор с кем-то из сферы) и уже по
ощущениям решает, идти дальше или сменить курс.
