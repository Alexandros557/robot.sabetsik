## 🌟 Что такое RoboCareer?

**RoboCareer** — это интерактивный Telegram-бот, который помогает познакомиться с IT-профессиями, определить свои интересы и найти подходящее направление для обучения.

Вместо скучного списка профессий пользователь проходит небольшой опрос, получает рекомендацию и может сразу попробовать себя в выбранной сфере с помощью практического задания.

🎯 **Наша цель:** сделать знакомство с IT простым, интересным и доступным каждому!

## 🚀 Как это работает?

1. Пользователь запускает бота командой `/start`.
2. Выбирает «Подобрать профессию».
3. Отвечает на вопросы о своих интересах.
4. RoboCareer анализирует ответы.
5. Бот предлагает подходящую профессию.
6. Пользователь получает практическое задание и учебные материалы.

## ⚙️ Установка и запуск

### 1. Клонирование проекта

```bash
git clone YOUR_REPOSITORY_LINK
cd RoboCareer
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Установка библиотек

Windows:

```powershell
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
```

### 4. Настройка токена

Получи токен у [@BotFather](https://t.me/BotFather).

В PowerShell:

```powershell
$env:TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN"
```

⚠️ Никогда не публикуй настоящий токен в GitHub!

### 5. Запуск бота

```powershell
& ".\.venv\Scripts\python.exe" ".\main.py"
```

## 📱 Команды Telegram-бота

| Команда | Назначение |
|---|---|
| `/start` | Запуск бота |
| `/quiz` | Профориентационный опрос |
| `/profile` | Просмотр профиля |
| `/help` | Помощь |
| `/cancel` | Отмена опроса |
| `/stats` | Количество пользователей |
